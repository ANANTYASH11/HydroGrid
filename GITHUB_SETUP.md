# 🚀 GitHub Setup Guide - HydroGrid Project

## Step 1: Create Repository on GitHub

1. Go to **https://github.com/new**
2. Enter repository name: `hydrogrid` (or your preferred name)
3. Choose visibility: **Public** or **Private**
4. Do NOT initialize with README (we have one)
5. Click **Create repository**

## Step 2: Copy Your Repository URL

After creating the repository, you'll see:
```
https://github.com/YOUR_USERNAME/hydrogrid.git
```

Or if using SSH:
```
git@github.com:YOUR_USERNAME/hydrogrid.git
```

## Step 3: Configure Git (First Time Only)

```powershell
# Set your username
git config --global user.name "Your Name"

# Set your email
git config --global user.email "your.email@gmail.com"
```

## Step 4: Add Remote and Push

In your project root directory:

```powershell
# Add GitHub as remote
git remote add origin https://github.com/YOUR_USERNAME/hydrogrid.git

# Stage all important files (respects .gitignore)
git add .

# Verify what will be committed
git status

# Create first commit
git commit -m "Initial commit: Complete HydroGrid full-stack application"

# Push to GitHub (use main branch)
git branch -M main
git push -u origin main
```

## Step 5: First Push with SSH (Optional)

If you want to use SSH instead:

```powershell
# First, set up SSH key (if not already done)
# Follow: https://docs.github.com/en/authentication/connecting-to-github-with-ssh

# Then update remote
git remote set-url origin git@github.com:YOUR_USERNAME/hydrogrid.git

# Push
git push -u origin main
```

## 🔐 SECURITY CHECKLIST

Before pushing, verify NO sensitive data is included:

```powershell
# Check if .env is in git
git ls-files --other --ignored --exclude-standard

# Should NOT show .env, .env.local, credentials, API keys
```

### ✅ Create .env.example (For Reference)

Create a template file showing required environment variables:

**File: `.env.example`**
```
# Backend
NODE_ENV=development
PORT=5001
MONGODB_URI=mongodb://localhost:27017/hydrogrid
JWT_SECRET=your_secret_key_here

# Frontend
VITE_API_URL=http://localhost:5001/api
```

**Never commit actual credentials!** Users will copy this to `.env` and add real values.

# HydroGrid - Water Utility Management System

## 🚀 Quick Start

### Prerequisites
- Node.js 20+
- MongoDB 5.0+
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/hydrogrid.git
cd hydrogrid
```

2. Install backend dependencies:
```bash
cd server
npm install
```

3. Install frontend dependencies:
```bash
cd ../client
npm install
```

4. Create `.env` files:

**server/.env:**
```
NODE_ENV=development
PORT=5001
MONGODB_URI=mongodb://localhost:27017/hydrogrid
JWT_SECRET=your_secret_key
```

**client/.env:**
```
VITE_API_URL=http://localhost:5001/api
```

5. Start MongoDB:
```bash
mongod
```

6. Start backend (from server folder):
```bash
npm run dev
```

7. Start frontend (from client folder):
```bash
npm run dev
```

8. Open browser:
```
http://localhost:5173
```

## 🆘 Troubleshooting

### Remote already exists
```powershell
git remote remove origin
git remote add origin https://github.com/YOUR_USERNAME/hydrogrid.git
```

### Permission denied
```powershell
# Try HTTPS instead
git remote set-url origin https://github.com/YOUR_USERNAME/hydrogrid.git
```

### Large files warning
```powershell
# Git LFS for large files (optional)
git lfs install
git lfs track "*.zip"
```

### Push rejected
```powershell
# Force push (use carefully!)
git push -u origin main --force
```
